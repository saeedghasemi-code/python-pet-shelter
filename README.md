# Pet Shelter Management System

A Python console-based application designed to manage a pet shelter, built using Object-Oriented Programming (OOP) principles.

## Features
- **Animal Management:** Add, search, and display different types of animals (Dogs, Cats, Birds, Snakes) using inheritance and polymorphism.
- **Adoption System:** Register adopters, handle animal adoption, and return animals to the shelter.
- **Data Validation:** Uses Regular Expressions (Regex) to validate adopter phone numbers and national IDs.
- **Custom Exceptions:** Handles specific errors (e.g., AnimalNotFound, AlreadyAdopted) gracefully.
- **Decorators:** Uses Python decorators for logging actions and data validation.
